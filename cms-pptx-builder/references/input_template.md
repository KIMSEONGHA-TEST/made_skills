# 입력 양식

다음 값은 작업 요청에서 받는다. 비어 있는 필수값을 임의로 채우지 않는다.

- 대상 자료:
- 주제:
- 결과 저장 위치:
- 결과 파일명:
- 대상 학습자:
- 수업 차시:
- 슬라이드 수:
- 글꼴:
- 디자인 기준 파일:
- 콘텐츠 브리프:
- PPT 아웃라인:
- 웹 사용 허용 여부:
- 추가 제한 사항:

## 필수값 판단

- `대상 자료`, `주제`, `결과 저장 위치`, `결과 파일명`은 제작 전 반드시 확정한다.
- 나머지 값이 없으면 원자료나 적용 규칙에서 확인한다.
- 원자료와 적용 규칙에서도 확인할 수 없고 결과에 중요한 영향을 주는 값은 사용자에게 묻는다.
- 사용자가 직접 정한 값은 요약하거나 다른 표기로 바꾸지 않는다.
