# cms-pptx-builder

## 목적

원자료의 범위를 벗어나지 않는 수업용 PPTX를 계획하고 새 파일로 제작한 뒤 실제 파일과 전체 슬라이드를 검증한다. 특정 대상 자료나 주제를 스킬에 고정하지 않는다.

## 입력 확인

작업을 시작할 때 [references/input_template.md](references/input_template.md)의 입력값을 확인한다.

- `대상 자료`와 `주제`는 필수 입력이다. 값이 없으면 추정하지 말고 사용자에게 묻는다.
- 결과 저장 위치가 없거나 여러 경로로 해석되면 절대경로 후보를 제시하고 확인한다.
- 사용자가 정한 대상, 차시, 슬라이드 수, 글꼴, 파일명은 그대로 사용한다.
- 파일명·폴더명·경로·스킬 이름·URL 같은 식별자는 원래 표기를 유지한다.

## 실행 원칙

- 적용되는 `AGENTS.md`와 PPTX 제작용 스킬이 있으면 먼저 읽고 그 규칙을 따른다.
- 원본은 읽기 전용으로 다루며 수정·이동·삭제·덮어쓰기하지 않는다.
- 원자료에 없는 사실, 수치, 사례, 출처를 추가하지 않는다.
- 사용자가 웹 사용을 금지했거나 자료 범위를 지정했다면 외부 검색을 하지 않는다.
- 새 폴더, 여러 파일, 기존 파일 덮어쓰기, 프로젝트 밖 저장이 필요하면 대상·절차·경로·검증 방법을 먼저 보여주고 승인을 기다린다.
- 지정 글꼴을 사용할 수 없으면 임의로 대체하지 않는다. `확인 필요`와 사용 가능한 대체 글꼴을 보고하고 사용자 결정을 기다린다.
- 제작에 들어가기 전 1차 제작 계획과 저장 예정 절대경로를 보여준다.

## 제작 절차

입력값과 저장 승인이 갖춰지면 [references/pptx_workflow.md](references/pptx_workflow.md)를 읽고 따른다. 핵심 순서는 다음과 같다.

1. 원자료, 콘텐츠 브리프, 아웃라인, 디자인 기준을 읽고 근거 범위를 고정한다.
2. 슬라이드 흐름, 메시지, 시각화 방식, 글꼴 상태, 확인 필요 항목을 계획으로 보고한다.
3. 필요한 승인을 받은 뒤 16:9 PPTX를 새 파일로 제작한다.
4. 모든 슬라이드에 정해진 세 항목만 포함한 발표자 노트를 기록한다.
5. 전체 슬라이드를 렌더링하고 각 장의 잘림·겹침·가독성·일관성을 육안으로 검사한다.
6. PPTX를 다시 열어 구조와 필수 조건을 검증한 뒤 최종 절대경로를 보고한다.

## 완료 조건

다음 조건을 모두 확인하기 전에는 완료로 보고하지 않는다.

- 결과 파일이 지정된 위치에 실제로 존재한다.
- PPTX가 정상적으로 다시 열리고 슬라이드 수와 16:9 비율이 맞는다.
- 제목 28pt 이상, 본문 18pt 이상이며 지정 글꼴만 사용했다.
- 모든 슬라이드의 노트가 스크립트 3~5문장, 교사 발문 1~2개, `[Sources]`로만 구성된다.
- 도표와 차트는 필요할 때 편집 가능한 개체이며, 수치 근거가 없으면 차트를 만들지 않는다.
- 전체 렌더링에서 잘림·겹침·화면 밖 배치가 없다.
- 원본이 수정·이동·삭제되지 않았고 승인되지 않은 위치에 결과물이 남지 않았다.
- 검증하지 못한 항목은 `확인 필요`로 표시한다.
